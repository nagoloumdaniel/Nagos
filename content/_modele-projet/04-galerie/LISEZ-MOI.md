# 04-galerie : Galerie

Fichiers : images + alt.json facultatif

```
Déposer 10 images maximum, les plus importantes (la 11e n'est jamais lue). Toutes tailles et tous formats d'image conviennent : le site adapte les cadres. Nom du fichier = légende : "01 - Page d'accueil.webp" donne "Page d'accueil".
Le préfixe numérique donne l'ordre. Formats : webp, png, jpg, avif, gif, svg (1600 px de large max, aucune donnée personnelle).
alt.json : {"01 - Page d'accueil.webp":"Description pour lecteur d'écran"}
```

Supprimer ce LISEZ-MOI une fois le dossier rempli (il est de toute façon ignoré par le site).
