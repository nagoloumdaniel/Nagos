Projet réalisé pour une cliente réelle : un salon indépendant dont les rendez-vous passaient par messagerie et téléphone. Le site propose un catalogue de prestations, un parcours de réservation guidé, une évaluation de compatibilité capillaire, des demandes sur mesure et une messagerie, avec un back-office pour tout gérer. Le paiement se fait sur place : le site ne traite aucune donnée de paiement. Le code est public à titre de portfolio, sous licence propriétaire.
